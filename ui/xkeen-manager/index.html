AntiGoblin

VPN-маршрутизация на Keenetic без возни с конфигами: добавь сервер, выбери что вести через VPN и примени.

Быстрый старт

Три шага до рабочего VPN

Сначала добавь ключ или подписку, потом выбери активный сервер и создай хотя бы одно правило трафика.

0 / 3
1 Добавь VPN-доступПодписка, URI или Hiddify / sing-box JSON → 2 Выбери активный серверИменно через него пойдут VPN-группы → 3 Настрой правилаДомены / CIDR → через VPN или мимо VPN →
Важно: routing.json применяется только к трафику устройств, назначенных политике Keenetic xkeen. Если счётчик перехвата в «Диагностике» остаётся 0 — назначь устройство в «Приоритеты подключений».
